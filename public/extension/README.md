# ChatWork 未読キープ送信 Chrome拡張機能 (Manifest V3)

ChatWorkのWeb画面を開かずにAPI経由でメッセージを送信することで、**既存の未読状態を維持したまま**定型文や連絡メッセージを送信できるGoogle Chrome拡張機能です。

---

## 🚀 Chromeへの導入手順（インストール方法）

1. **拡張機能のファイルを準備する**
   - 本フォルダ（`manifest.json`, `popup.html`, `popup.css`, `popup.js`, `icons/` を含むディレクトリ）を用意します。
   - アプリケーション画面上の「一括ダウンロード (ZIP)」ボタンを押してZIPを取得し、解凍したフォルダを利用することも可能です。

2. **Chromeの拡張機能管理画面を開く**
   - Google Chromeを開き、URLバーに `chrome://extensions` と入力してEnterを押します。
   - または、右上の「︙（設定）」＞「拡張機能」＞「拡張機能を管理」を選択します。

3. **デベロッパーモードをONにする**
   - 画面右上にある **「デベロッパーモード」** のトグルスイッチをONにします。

4. **拡張機能を読み込む**
   - 左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
   - 本拡張機能のフォルダ（`manifest.json` が入っているフォルダ）を選択します。

5. **ピン留めして利用開始**
   - Chromeツールバーのパズルピース型アイコン（拡張機能メニュー）から「ChatWork 未読キープ送信」を探し、ピン留め（📌）しておくとワンクリックで呼び出せます。

---

## 🔑 ChatWork APIトークンの取得方法

1. ChatWork（https://www.chatwork.com/）にログインします。
2. 画面右上のご自身のアカウント名・アイコンをクリックし、**「サービス連携」** を選択します。
3. 左側メニューの **「APIトークン」** をクリックします。
4. パスワードを入力して「表示」をクリックすると、APIトークン文字列が表示されます。
5. コピーして拡張機能の設定画面に貼り付け、「トークンを保存」を押してください。

## 🛠 主な機能

- **未読ステータス保護**: ChatWork画面を開かずにAPI（`POST /rooms/{room_id}/messages` または `POST /rooms/{room_id}/files`）経由で送信するため、相手から届いている未読メッセージを開封（既読）にせずに自分のメッセージだけを送れます。
- **動的ルーム取得 ＆ インクリメンタル絞り込み検索**: `GET /rooms` で参加中ルーム一覧を自動取得し、検索窓に入力するだけで瞬時にルームを絞り込めます。
- **定型文テンプレート管理**: 始業・終業日報、受領確認などの定型文を保存・編集・削除・ワンクリック呼び出しできます。
- **送信前編集**: テンプレートを選択した後、追記事項や相手のお名前などを自由に微調整してから送信できます。
- **📷 写真・画像添付（任意設定）**:
  - メッセージ送信時に任意で画像ファイル（PNG, JPG, GIF, WebP / 最大5MB）を添付可能。
  - ドラッグ＆ドロップまたはファイル選択に対応し、選択した写真のサムネイルとファイルサイズをリアルタイムプレビュー。
  - 添付時は `multipart/form-data` 形式で `POST /rooms/{room_id}/files` を呼び出し、ChatWork上で写真とメッセージが同時に投稿されます。
  - 添付解除ボタンですぐに通常メッセージ送信に戻すことができます。
